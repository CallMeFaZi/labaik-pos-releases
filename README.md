# Labaik POS — downloads

Software for **Labaik Ya Rasool Allah Oil Store & Car Wash**.

This repository only contains the installer and signed update files. The source code is private.

## Install (first time)
1. Open **[Releases](../../releases/latest)** and download `LabaikPOS-Setup-<version>.exe`.
2. Double-click it. If Windows shows *"Windows protected your PC"*, click **More info → Run anyway** (the installer is not code-signed yet).
3. Open **Labaik POS** from the desktop and create the owner account.

## Updates
Installed shops find new versions under **Settings → Updates** and install them with one click.
Shops without internet can install the `.labaik-update` file from the same page.
Every update is digitally signed; the app refuses files that are not.
